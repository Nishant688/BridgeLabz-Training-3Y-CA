1. What is jQuery?
jQuery is a fast, small, and feature-rich JavaScript library designed to simplify HTML DOM traversal and manipulation.
2. How does event delegation work in jQuery?
Event delegation leverages event bubbling by attaching a single handler to a common parent using .on('event', 'selector', fn).
3. What is the difference between .empty() and .remove()?
.empty() removes all child nodes inside an element, while .remove() deletes the target element and its children from the DOM.
4. How do you handle animations smoothly?
jQuery provides .animate(), .slideToggle(), and .fadeToggle() which integrate with CSS properties and easing functions.
5. Can multiple jQuery versions coexist on one page?
Yes! jQuery.noConflict(true) restores global variables and returns a unique handle for each loaded library instance.
